# Contributing to recitbot-screen-recorder

Thanks for looking at the recorder.

## Bug reports: yes, please

Open an [issue](../../issues/new) with:

- the platform and version (Windows 10/11 build, or macOS version; recorder version from `--selftest` output or the
  install result line),
- what you expected and what happened,
- the relevant lines from the recorder's log (remove anything private first: device names, window titles, links),
- whether it reproduces with a recorder you built from this repository.

Never post pairing codes, device tokens, upload tokens, `config.dat` contents or video links in an issue.

## Pull requests: not accepted yet

We are not accepting outside pull requests or patches at this time, and pull requests will be closed without review.
This keeps the licensing of the code simple while the project is new. If you have found a fix, describe it in an issue
(a short snippet in the issue is fine); we may implement it ourselves. We will update this file if that changes.

## Security problems

Do not open a public issue for a vulnerability. Follow [SECURITY.md](SECURITY.md).
