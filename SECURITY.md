# Security policy

Please report vulnerabilities privately through GitHub's **"Report a vulnerability"** button on this repository's
**Security** tab (private vulnerability reporting). Do not open a public issue.

In scope: the recorder in this repository (command verification, pairing, uploads, self-update and installer hash
checks, link policy, local storage of pairing secrets, the install and uninstall scripts).

Please include the recorder version and platform, the steps to reproduce, and the impact you expect. We will
acknowledge the report, keep you updated, and credit you in the release notes if you want.

Supported versions: the latest release only (the recorder updates itself).
